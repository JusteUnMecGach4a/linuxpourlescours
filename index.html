Le Terminal Linux

Guide des commandes essentielles pour les distributions basées sur Debian (ex: LMDE, Mint, Ubuntu)

1. Mise à jour et Installation (LMDE/Debian)

apt update

Cliquez pour plus

Mise à jour de l'index des paquets disponibles à partir des sources configurées (dépôts). **Crucial** avant toute installation.

sudo apt update

Doit être effectué avant toute installation ou mise à jour pour que le système connaisse les dernières versions.

Nettoyer le cache :

sudo apt clean

Supprime les fichiers de paquets téléchargés mais non utilisés, libérant de l'espace disque.

apt upgrade

Cliquez pour plus

Met à jour tous les paquets installés vers leurs versions les plus récentes. Elle **n'installe ni ne supprime** de paquets.

sudo apt upgrade

C'est la méthode de mise à jour standard et recommandée pour la majorité des cas.

Mise à jour complète :

sudo apt dist-upgrade

Effectue une mise à jour de la distribution; peut **installer/supprimer** des paquets pour résoudre des dépendances, souvent utilisé lors d'un changement de version majeure de l'OS.

apt install

Cliquez pour plus

Télécharge et installe un nouveau paquet ou logiciel, ainsi que toutes ses dépendances nécessaires.

sudo apt install PACKAGE

Remplace l'ancienne commande `apt-get install`. Vous pouvez lister plusieurs paquets à installer en même temps.

Désinstallation :

sudo apt remove PACKAGE

Désinstalle le paquet. Utilisez **sudo apt purge PACKAGE** pour supprimer le paquet et ses fichiers de configuration (recommandé pour un nettoyage complet).

2. Gestion des Fichiers et Dossiers

cd

Cliquez pour plus

Change directory - **navigue** et change le répertoire de travail actuel dans le terminal.

cd [DIRECTORY | PATH]

Aller au répertoire cd / (racine), cd .. (remonter d'un niveau), cd ~ (répertoire personnel), ou simplement **cd** seul pour aller au répertoire personnel.

Naviguer rapidement :

cd -

Retourne au **dernier** répertoire visité. Très pratique pour basculer entre deux dossiers.

ls

Cliquez pour plus

list - Affiche la liste des fichiers et sous-répertoires contenus dans un répertoire.

ls -la

Options clés : -l (format long, pour voir les permissions), -a (affiche les fichiers cachés, commençant par un point).

Autres utilisations courantes :

ls -lh

Affiche le format long avec les tailles lisibles par l'humain (Mo, Go, etc.).

mkdir

Cliquez pour plus

Make Directory - Crée un nouveau répertoire à l'emplacement spécifié.

mkdir NOUVEAU_DOSSIER

L'option -p est très utile pour créer des dossiers parents s'ils n'existent pas encore.

Création imbriquée :

mkdir -p backup/images/2025

Crée tous les dossiers nécessaires en une seule commande.

rmdir

Cliquez pour plus

Remove Directory - Supprime un répertoire, **mais uniquement s'il est vide**.

rmdir DOSSIER_VIDE

Pour un répertoire non vide, il faut utiliser la commande `rm` avec l'option `-r` (récursif).

Suppression récursive (Non vide) :

rm -r DOSSIER_NON_VIDE

**Attention** : La suppression avec `rm -r` est permanente et ne passe pas par la corbeille.

cp -R

Cliquez pour plus

Copy - Copie récursivement un répertoire, y compris tout son contenu (sous-dossiers et fichiers) vers une destination.

cp -R SOURCE DEST

L'option -R est **obligatoire** pour copier un dossier entier et non seulement son nom.

Copie de fichiers spécifiques :

cp *.log /var/log/backup/

Copie tous les fichiers terminant par `.log` dans le dossier de destination.

mv

Cliquez pour plus

Move - **Déplace** un fichier ou un répertoire vers un autre emplacement, ou le **renomme** si la destination est dans le même répertoire.

mv old_dir new_dir

La commande mv est la même pour les fichiers ou les répertoires. Il n'y a pas de commande `rename` dédiée en standard.

Déplacement :

mv fichier.tmp /tmp/

Déplace le fichier `fichier.tmp` dans le répertoire temporaire `/tmp/`.

touch

Cliquez pour plus

Crée un nouveau fichier **vide** s'il n'existe pas, ou **met à jour l'horodatage** (date et heure de dernière modification) d'un fichier existant.

touch FILE

Souvent utilisé pour créer rapidement un fichier placeholder ou pour marquer un fichier comme récemment modifié.

Créer un script shell :

touch script.sh && chmod +x script.sh

Crée un fichier et le rend immédiatement exécutable.

cat

Cliquez pour plus

Concatenate - Affiche le contenu complet d'un fichier directement dans la sortie standard. Idéal pour les petits fichiers de configuration.

cat FILE

Pour les fichiers volumineux, il est fortement recommandé d'utiliser `less` pour éviter de submerger le terminal.

Afficher avec numéros de lignes :

cat -n fichier.txt

Affiche le contenu en numérotant chaque ligne, utile pour le débogage.

less

Cliquez pour plus

Affiche le contenu d'un fichier **page par page**, permettant la navigation et la recherche sans charger tout le fichier en mémoire.

less FILE

Naviguez avec les flèches ou la barre d'espace. Quittez l'affichage avec la touche Q. C'est le visualiseur de logs par excellence.

Rechercher dans less :

/terme (puis n pour l'occurrence suivante)

Une fois dans `less`, tapez `/` suivi de votre motif pour rechercher un mot de haut en bas.

nano

Cliquez pour plus

Lance l'éditeur de texte **nano** dans le terminal. Il est simple et convivial, idéal pour les débutants et l'édition rapide de fichiers de configuration.

nano FILE

Les commandes sont affichées en bas de l'écran : Ctrl+O pour enregistrer et Ctrl+X pour quitter.

Édition avec droits root :

sudo nano /etc/network/interfaces

Utilisation obligatoire de **sudo** pour modifier les fichiers système.

rm

Cliquez pour plus

Remove - **Supprime** définitivement un fichier ou un répertoire (avec l'option `-r`).

rm fichier_a_supprimer.log

Utilisez **-r** pour les dossiers et **-f** pour forcer la suppression sans confirmation.

Supprimer en mode sécurisé :

rm -i fichier.txt

Le mode interactif (-i) demande confirmation pour chaque suppression, une bonne habitude à prendre.

3. Recherche et Emplacement

find (dir)

Cliquez pour plus

Recherche des fichiers ou répertoires dans une arborescence selon des critères précis (nom, type, taille, date, etc.).

find / -type d -name "DIRECTORY"

**-type d** spécifie que l'on recherche un **dossier** (`directory`). **/** indique de commencer la recherche à la racine du système.

Recherche insensible à la casse :

find /home -iname "Rapports"

Utiliser **-iname** au lieu de `-name` pour ignorer la distinction majuscules/minuscules.

find (file)

Cliquez pour plus

Rechercher un fichier spécifique à partir d'un point de départ donné.

find / -type f -name "FILE"

**-type f** spécifie que l'on recherche un **fichier** (`file`). L'astérisque `*` peut être utilisé pour les jokers : `find . -name "*.jpg"`.

Recherche par taille :

find /var -size +10M

Trouve les fichiers de plus de 10 Mégaoctets dans le répertoire `/var`.

locate

Cliquez pour plus

Recherche des fichiers très rapidement en consultant une **base de données** pré-indexée du système de fichiers.

locate FILE

La base de données doit être mise à jour périodiquement (souvent la nuit) ou manuellement avec **sudo updatedb**.

Mise à jour de la base :

sudo updatedb

Si vous venez de créer un fichier et que `locate` ne le trouve pas, exécutez cette commande.

whereis

Cliquez pour plus

Recherche les fichiers binaires, la documentation (manuel) et les sources d'un programme donné.

whereis PROGRAM

Utile pour les administrateurs qui cherchent où se trouvent les fichiers de configuration ou la documentation locale du programme.

Exemple :

whereis bash

Donne l'emplacement du binaire (`/bin/bash`) et du manuel (`/usr/share/man/man1/bash.1.gz`).

which

Cliquez pour plus

Affiche le **chemin complet** du binaire qui sera exécuté par le shell pour une commande donnée. Répond à la question "quelle version de ce programme j'utilise ?".

which COMMAND

Indique le chemin d'exécution réel, utile quand plusieurs versions du même outil sont installées.

Vérification du path :

which python3

Confirme l'emplacement exact de l'interpréteur Python 3 utilisé par défaut.

4. Texte, Pipes et Redirections

grep

Cliquez pour plus

Global Regular Expression Print - **Recherche** des lignes correspondant à un motif (PATTERN) dans un ou plusieurs fichiers.

grep PATTERN FILE

Options clés : -i (ignorer la casse), -n (afficher le numéro de ligne), et -v (inverser la recherche, pour exclure le motif).

Recherche récursive dans les logs :

grep -r "Erreur fatale" /var/log/

Recherche le motif dans tous les fichiers à partir de `/var/log/`.

cut

Cliquez pour plus

Coupe des lignes de texte en sections (champs) basées sur un délimiteur spécifié, permettant d'extraire des colonnes de données.

cut -d':' -f2 FILE

**-d** définit le délimiteur (ici `:`) et **-f** (field) le champ (colonne) à afficher.

Extraire les noms d'utilisateur et l'ID :

cat /etc/passwd | cut -d':' -f1,3

Affiche la première colonne (nom d'utilisateur) et la troisième colonne (UID) du fichier `/etc/passwd`.

sort

Cliquez pour plus

Trie les lignes d'un fichier texte ou d'une entrée selon un ordre alphabétique par défaut.

sort FILE

Utilisez **-r** pour trier à l'envers (ordre alphabétique inverse ou numérique décroissant).

Trier numériquement :

sort -n data.txt

Force le tri numérique (-n) au lieu du tri par chaîne de caractères. Très important pour les nombres.

| (Pipe)

Cliquez pour plus

Le **Pipe** (`|`) **chaîne** les commandes en redirigeant la **sortie** standard de la première commande vers l'**entrée** standard de la seconde.

COMMAND_1 | COMMAND_2

Permet de créer des scripts complexes en combinant des utilitaires simples pour filtrer ou transformer des données.

Filtrer des processus :

ps aux | grep "apache"

Affiche tous les processus en cours, puis utilise `grep` pour filtrer uniquement ceux qui contiennent le mot "apache".

> / >>

Cliquez pour plus

Dirige la sortie standard d'une commande vers un fichier. **>** écrase le contenu. **>>** ajoute le contenu à la fin du fichier.

COMMAND > OUT

**>>** est crucial pour les opérations de journalisation (`logging`), car il conserve les données précédentes.

Archiver une liste de fichiers :

ls -l > liste_fichiers.txt

Écrit la sortie de `ls -l` dans le fichier `liste_fichiers.txt`, écrasant son contenu s'il existe déjà.

5. Utilisateurs, Groupes et Permissions

adduser / deluser

Cliquez pour plus

**adduser** est un script convivial qui crée un nouvel utilisateur, son répertoire personnel, et demande son mot de passe. Il est **recommandé** sur Debian/LMDE plutôt que `useradd`.

sudo adduser USER

**deluser** supprime un utilisateur. Il faut ajouter `sudo` car ce sont des commandes d'administration.

Suppression complète :

sudo deluser --remove-home USER

Supprime l'utilisateur **et** son répertoire personnel pour un nettoyage complet du système.

passwd

Cliquez pour plus

Modifie le mot de passe d'un utilisateur existant. C'est l'outil standard pour la gestion des mots de passe dans Linux.

passwd

Si vous êtes simple utilisateur et exécutez **passwd**, vous changez votre propre mot de passe. Si vous utilisez **sudo passwd USER**, vous changez celui d'un autre utilisateur sans connaître l'ancien.

Changer le mot de passe d'un utilisateur (Admin) :

sudo passwd mon_utilisateur

Cette commande permet à l'administrateur de forcer le changement de mot de passe d'un utilisateur sans avoir besoin de l'ancien mot de passe.

mkpasswd

Cliquez pour plus

Génère des mots de passe **hachés** (cryptés) en utilisant différents algorithmes. Utile pour la gestion des comptes via des scripts ou la modification des fichiers `shadow`.

mkpasswd -m sha-512

L'option **-m sha-512** utilise l'algorithme SHA-512, le standard le plus sécurisé dans les systèmes Linux récents.

Générer un mot de passe sécurisé :

mkpasswd -l 15 -d 3 -c 3 -C 3 -s 0

Génère un mot de passe de 15 caractères, incluant au moins 3 chiffres, 3 minuscules et 3 majuscules, sans symboles.

addgroup / delgroup

Cliquez pour plus

Crée ou supprime un groupe du système. Les groupes sont utilisés pour gérer les permissions d'accès partagées entre plusieurs utilisateurs.

sudo addgroup GROUP

La gestion des utilisateurs et des groupes est une base fondamentale de l'administration Linux.

Ajouter un utilisateur à un groupe secondaire :

sudo usermod -aG GROUP USER

La commande **usermod** avec l'option **-aG** ajoute l'utilisateur au groupe sans le retirer des autres groupes.

chown

Cliquez pour plus

Change Owner - Modifie le **propriétaire** et/ou le **groupe** d'un fichier ou d'un répertoire.

sudo chown OWNER:GROUP FILE

Le `:` (deux-points) sépare le propriétaire du groupe. L'utilisation de `sudo` est souvent requise.

Changer le propriétaire et le groupe récursivement :

sudo chown -R www-data:www-data /var/www/html

Change le propriétaire et le groupe pour le serveur web, y compris pour tous les sous-dossiers et fichiers (-R).

chmod

Cliquez pour plus

Change Mode - Modifie les **permissions** d'accès d'un fichier (lecture, écriture, exécution) en utilisant la notation octale (chiffres) ou symbolique.

sudo chmod 755 FILE

**755** (propriétaire: rwx, groupe: rx, autres: rx). La commande chmod +x est une alternative pour rendre exécutable.

Notation symbolique :

chmod u+w,o-rwx FILE

Donne l'écriture au propriétaire (u+w) et enlève toutes les permissions aux autres (o-rwx).

6. Système et Diagnostic

kill

Cliquez pour plus

Envoie un **signal** à un processus pour le contrôler ou le terminer. Le processus est identifié par son **PID** (Process ID) que vous pouvez trouver avec `ps` ou `top`.

kill PID

Par défaut, envoie le signal TERM (15), demandant au processus de s'arrêter proprement (sauvegarde des données avant arrêt).

Terminaison forcée :

kill -9 PID

Envoie le signal **KILL (9)** qui arrête immédiatement le processus, sans lui laisser le temps de s'arrêter proprement (à utiliser seulement si `kill PID` ne fonctionne pas).

systemctl

Cliquez pour plus

Outil principal pour contrôler le système d'initialisation **systemd** sur les distributions modernes (comme LMDE). Il gère l'état des services et des unités système.

sudo systemctl restart apache2

Les commandes clés sont start, stop, restart, enable (activer au démarrage) et disable (désactiver au démarrage).

État du service :

systemctl status nom_service

Vérifie l'état actuel d'un service, si il est actif, les logs récents et le PID du processus principal.

top / htop

Cliquez pour plus

Surveillent en **temps réel** l'activité du système, affichant l'utilisation du CPU, de la mémoire, et la liste des processus triés par charge. **htop** est souvent préféré pour son interface plus lisible.

htop

Utilisez-les pour identifier les processus qui consomment le plus de ressources et les PID avant d'utiliser `kill`.

Tuer un processus via htop :

Dans htop, sélectionnez un processus, puis appuyez sur **F9** pour envoyer un signal de terminaison (équivalent à `kill`).

df / du

Cliquez pour plus

**df** (Disk Free) affiche l'espace disque **disponible** sur les systèmes de fichiers montés. **du** (Disk Usage) affiche l'espace disque **utilisé** par des fichiers et répertoires.

df -h ; du -sh *

L'option -h (human-readable) est essentielle pour un affichage en Mo, Go, etc.

Trouver les plus gros dossiers :

du -h --max-depth=1 | sort -hr

Affiche la taille de chaque sous-répertoire triée par taille décroissante (un outil puissant de nettoyage).

7. Sécurité et Pentest

john (John the Ripper)

Cliquez pour plus

Outil de test de sécurité utilisé pour **détecter les mots de passe faibles** sur les systèmes Unix/Linux en effectuant des attaques par dictionnaire ou par force brute. Souvent utilisé après l'extraction des hachages.

john --wordlist=rockyou.txt hashes.txt

John travaille principalement sur des fichiers contenant des **hachages** de mots de passe (souvent extraits du fichier `/etc/shadow`).

Afficher les mots de passe crackés :

john --show hashes.txt

Affiche uniquement les mots de passe que l'outil a réussi à déchiffrer dans la session précédente.

unshadow

Cliquez pour plus

Commande utilitaire de John the Ripper. Elle combine les fichiers `/etc/passwd` et `/etc/shadow` en un seul fichier de format lisible par `john`.

sudo unshadow /etc/passwd /etc/shadow > hashes.txt

Le fichier de sortie `hashes.txt` contient les noms d'utilisateurs et leurs hachages associés, prêts à être analysés par **john**.

Processus typique :

1. Extraire les hachages avec **unshadow**. 2. Lancer l'outil **john** sur le fichier généré. 3. Utiliser `john --show` pour voir les résultats.
