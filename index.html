Le Terminal Linux

Guide des commandes essentielles pour les distributions basées sur Debian (ex: LMDE, Mint, Ubuntu)

1. Mise à jour et Installation (LMDE/Debian)

apt update

Cliquez pour plus

Mise à jour des dépôts (liste les paquets disponibles).

sudo apt update

Doit être effectué avant toute installation ou mise à jour.

Autres utilisations :

sudo apt clean

Nettoyer le cache local des paquets téléchargés.

apt upgrade

Cliquez pour plus

Mise à jour des paquets installés (sans supprimer de paquets).

sudo apt upgrade

Met à jour la majorité des paquets en toute sécurité.

Différence avec dist-upgrade :

sudo apt dist-upgrade

Mise à jour de la distribution (peut installer/supprimer des paquets pour résoudre les dépendances).

apt install

Cliquez pour plus

Installation d'un nouveau paquet ou logiciel.

sudo apt install PACKAGE

Remplace l'ancienne commande `apt-get install`.

Désinstallation :

sudo apt remove PACKAGE

Désinstalle le paquet, mais garde les fichiers de configuration. Utilisez `purge` pour tout supprimer.

2. Gestion des Fichiers et Dossiers

cd

Cliquez pour plus

Change directory - Charger un répertoire ou un chemin.

cd [DIRECTORY | PATH]

Aller au répertoire **cd /** (racine), **cd ..** (remonter), **cd ~** (perso).

Autres utilisations :

cd /usr/bin

Charger un répertoire à partir de la racine.

ls

Cliquez pour plus

list - Afficher le contenu d'un répertoire.

ls -la

Options : **-l** (format long), **-a** (affiche cachés).

Autres utilisations :

ls -l | less

Afficher la liste longue page par page.

mkdir

Cliquez pour plus

Créer un nouveau répertoire.

mkdir NOUVEAU_DOSSIER

Utilisez **-p** pour créer les dossiers parents.

Autres utilisations :

mkdir -p backup/{images,docs}

Créer plusieurs sous-répertoires imbriqués en une seule fois.

rmdir

Cliquez pour plus

Supprimer un répertoire vide.

rmdir DOSSIER_VIDE

Ne fonctionne que si le répertoire est vide.

Pour un dossier non vide :

rm -r DOSSIER_NON_VIDE

Utilisez `rm -r` pour une suppression récursive (dangereux !).

cp -R

Cliquez pour plus

Copier récursivement un répertoire.

cp -R SOURCE DEST

L'option **-R** (ou -r) est obligatoire pour les dossiers.

Autres utilisations :

cp -a /source /destination

Copier en mode archive (préserve les permissions, propriétaires, etc.).

mv

Cliquez pour plus

Déplacer ou renommer un répertoire.

mv old_dir new_dir

Identique pour les fichiers ou les répertoires.

Déplacer :

mv mon_dossier /tmp/backups/

Déplace le dossier `mon_dossier` dans `/tmp/backups/`.

touch

Cliquez pour plus

Créer un nouveau fichier vide.

touch FILE

Également utilisé pour mettre à jour l'horodatage d'un fichier existant.

Mise à jour d'heure :

touch -t 202501011000 fichier.txt

Définir l'horodatage au 1er janvier 2025 à 10:00.

cat

Cliquez pour plus

Afficher le contenu complet du fichier.

cat FILE

Idéal pour les petits fichiers. Utilisez `less` pour les grands.

Concaténation :

cat f1.txt f2.txt > f_combo.txt

Combiner le contenu de deux fichiers dans un troisième.

less

Cliquez pour plus

Afficher le contenu du fichier page par page.

less FILE

Naviguez avec les flèches ou la barre d'espace. Quitter avec **Q**.

Recherche :

/terme

Dans `less`, tapez `/terme` pour rechercher un mot.

nano

Cliquez pour plus

Éditer un fichier (éditeur de texte simple).

nano FILE

Utilisez **Ctrl+O** pour enregistrer et **Ctrl+X** pour quitter.

Autres options :

sudo nano /etc/default/grub

Éditer un fichier système nécessitant des privilèges root.

rm

Cliquez pour plus

Supprimer un fichier (soyez prudent !).

rm fichier_a_supprimer.log

Utilisez **-r** pour les dossiers et **-f** pour forcer la suppression.

ATTENTION :

rm -i fichier.txt

Mode interactif (**-i**) pour demander confirmation avant de supprimer.

3. Recherche et Emplacement

find (dir)

Cliquez pour plus

Rechercher un répertoire à partir de la racine.

find / -type d -name "DIRECTORY"

**-type d** spécifie une recherche de répertoire.

Recherche sensible à la casse :

find /home -iname "images"

Utiliser **-iname** pour ignorer la casse lors de la recherche de fichiers/dossiers.

find (file)

Cliquez pour plus

Rechercher un fichier à partir de la racine.

find / -type f -name "FILE"

**-type f** spécifie une recherche de fichier.

Recherche par taille :

find /var -size +10M

Trouver les fichiers de plus de 10 Mo dans `/var`.

locate

Cliquez pour plus

Rechercher un fichier rapidement (utilise une base de données).

locate FILE

Mettez à jour la base de données avec **sudo updatedb**.

Mise à jour de la base :

sudo updatedb

Mise à jour manuelle de la base de données `locate`.

whereis

Cliquez pour plus

Rechercher l'emplacement d'un programme (binaire, source et manuel).

whereis PROGRAM

Utile pour trouver les fichiers de configuration associés.

Exemple :

whereis bash

Affiche où se trouvent le binaire bash et sa documentation.

which

Cliquez pour plus

Rechercher le répertoire du binaire d'une commande.

which COMMAND

Indique le chemin d'exécution utilisé par le shell.

Utile pour :

which python

Vérifier quel binaire Python est utilisé sur votre système.

4. Texte, Pipes et Redirections

grep

Cliquez pour plus

Rechercher un terme (PATTERN) dans un fichier.

grep PATTERN FILE

Utilisez **-i** (ignorer la casse) ou **-n** (numéro de ligne).

Autres utilisations :

grep -r "erreur" /var/log/

Recherche récursive (**-r**) d'un motif dans un répertoire.

cut

Cliquez pour plus

Couper des champs en fonction d'un délimiteur.

cut -d':' -f2 FILE

**-d** délimiteur, **-f** champ à afficher.

Exemple :

cat /etc/passwd | cut -d':' -f1

Afficher la liste de tous les noms d'utilisateurs (`:` est le délimiteur).

sort

Cliquez pour plus

Trier les lignes d'un fichier alphabétiquement (par défaut).

sort FILE

Utilisez **-r** pour trier à l'envers (reverse).

Trier par nombre :

sort -n numbers.txt

Trier numériquement (**-n**) au lieu d'alphabétiquement.

| (Pipe)

Cliquez pour plus

Transfère le résultat (la sortie standard) d'une commande à une autre commande.

COMMAND_1 | COMMAND_2

Le Pipe permet de chaîner des opérations complexes.

Exemple :

ls -l | grep "janvier"

Liste tous les fichiers de janvier dans le répertoire actuel.

> / >>

Cliquez pour plus

Redirection de la sortie : écrasement (>) ou ajout (>>).

COMMAND > OUT

**>>** est crucial pour ajouter des logs sans effacer le fichier.

Exemple d'ajout :

echo "ligne 3" >> mon_fichier.txt

Ajoute "ligne 3" à la fin de `mon_fichier.txt`.

5. Utilisateurs, Groupes et Permissions

adduser

Cliquez pour plus

Ajouter un nouvel utilisateur au système.

sudo adduser USER

Crée le répertoire personnel, configure les shells et demande le mot de passe.

Supprimer un utilisateur :

sudo deluser USER

Supprime l'utilisateur. Ajoutez `--remove-home` pour supprimer son répertoire personnel.

passwd

Cliquez pour plus

Modifier le mot de passe d'un utilisateur.

sudo passwd [USER]

Si `USER` est omis, modifie le mot de passe de l'utilisateur courant.

Exemple :

passwd

Changer votre propre mot de passe.

addgroup / delgroup

Cliquez pour plus

Ajouter ou supprimer un groupe.

sudo addgroup GROUP

La suppression se fait avec **sudo delgroup GROUP**.

Ajouter un utilisateur à un groupe :

sudo usermod -aG GROUP USER

Ajouter l'utilisateur au groupe sans le retirer des autres (**-aG**).

chown

Cliquez pour plus

Changer le propriétaire et/ou le groupe d'un fichier/dossier.

sudo chown OWNER:GROUP FILE

Utilisez **OWNER:GROUP** pour changer les deux simultanément.

Changer seulement le groupe :

sudo chown :GROUP FILE

Laisser le propriétaire vide mais spécifier le groupe change uniquement le groupe.

chmod

Cliquez pour plus

Changer les permissions d'un fichier/dossier.

sudo chmod 755 FILE

**755** (propriétaire: rwx, groupe: rx, autres: rx). **chmod +x** rend exécutable.

Changer symboliquement :

chmod u+w,g-w,o-rwx FILE

Donne l'écriture au propriétaire (**u+w**), enlève l'écriture au groupe (**g-w**), enlève toutes les permissions aux autres (**o-rwx**).

6. Système et Diagnostic

systemctl

Cliquez pour plus

Contrôle le système d'initialisation **systemd** (gestion des services).

sudo systemctl restart apache2

Commandes clés : **start**, **stop**, **restart**, **enable**, **disable**.

État du service :

systemctl status nom_service

Vérifier l'état actuel d'un service (actif, inactif, etc.).

top / htop

Cliquez pour plus

Surveille l'activité du système (processus, mémoire, CPU) en temps réel.

htop

**htop** est une version plus conviviale de **top**.

Raccourci htop :

Appuyez sur **F4** pour filtrer la liste des processus par nom.

df / du

Cliquez pour plus

**df** (Disk Free) espace disponible. **du** (Disk Usage) espace utilisé par les fichiers.

df -h ; du -sh *

L'option **-h** affiche les tailles lisibles par un humain.

Utilisation avancée :

du -h --max-depth=1

Affiche la taille de chaque dossier de premier niveau dans le répertoire actuel.
